# **App Name**: Banesco Seguros: Expedition

## Core Features:

- Dashboard Overview: Display the user's avatar, current level's 'world', XP progress, and a list of level objectives, offering a comprehensive overview of the user's progression.
- Task Completion & XP System: Allow users to mark tasks as complete to earn 'Expedition Points' (XP), contributing to level progression and unlocking new avatars and worlds. Update the UI to reflect task completion and XP gains.
- Detailed Task View: Provide a 'Task History' screen that allows users to view complete task details including any supporting documentation.
- Leaderboard Ranking: Enable a 'Ranking' screen displaying users' positions and performance, promoting competition and engagement.
- Personalized Avatar Profile: Allow users to track avatar progression in the personal profile with unlocked avatars shown in color, while the future evolutions are shown grayed out. This features includes gamified statistics such as number of tasks completed.

## Style Guidelines:

- Primary color: Dark corporate blue (#003c71) for the navigation bar, main buttons, and icons, providing a professional and branded feel.
- Background: Pure white (#FFFFFF) to ensure a clean and uncluttered interface.
- Text: Use almost black (#1A1A1A) for main text and medium gray (#888888) for secondary text or accents to maintain legibility.
- Font: Use 'Poppins' (sans-serif) with 'Poppins Bold' for titles, 'Poppins SemiBold' for subtitles, and 'Poppins Regular' for body text.
- Icons: Utilize a simple and recognizable line-style icon set. Use check (✓) and cross (✗) icons for task status.
- Cards: Implement cards with slightly rounded corners and subtle shadows for the tasks.
- Illustrations: 3D stylized and friendly visuals for the character's avatar and level environments.
